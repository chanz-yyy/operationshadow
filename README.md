# Northstar Labs — Trace the Attack

A self-contained static HTML incident-correlation and triage tool for the fictional Round 2 case.

## Run
Open `index.html` in any modern browser. No installation, server, API key, or internet connection is necessary.

## Features
- Nine events in chronological order, with observed evidence and caveats.
- Filter security signals or show all events; copy the timeline.
- Three strongest indicators and hypothesis-based attack path.
- Prioritized containment, verification, recovery, and monitoring workflow.
- Evidence gaps and explicit no-confirmed-exfiltration finding.
- Generate, copy, and download an incident report.

## Evidence discipline
All events are derived strictly from the supplied fictional case file. The proposed attack path is marked as a hypothesis. There is no verified file download or forwarded-message delivery. The app makes no network requests.
